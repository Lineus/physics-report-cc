# 分支 B：正式实验报告（`N/`）

原始记录已签字、要交的成稿。预习稿见 `references/prep.md`。

## 铁律

1. 一段脚本一段产物：`calc.py → calc.json` → `figs.py → fig*.png` → `build.py → *.docx` → 导出 PDF。不写巨型脚本，出错时无法定位在哪段。
2. 数据只从原始记录照片读，不从讲义例题、理论值、别人数据反推；字迹不清就放大看图，不猜。
3. 每个物理量先自检：打印「实测 / 理论 / 相对误差」，>2% 先查原因再写进报告。
4. 版面只在 PDF 里验，不看 docx 自查（Word 分页逻辑 python-docx 复现不了）。

## 输入清单（缺一项先问，不自己编）

原始记录照片（含签字）/ 预习报告 docx / 课件 PDF / 模板 docx / 课表（日期、桌号、指导教师）。
照片可以直接发给 Agent，也可以放进 `N/`（按 `原始记录*`、`思考题*` 匹配）。

## Step 1 算数据（`calc.py` → `calc.json`）

一段脚本产出**全部**数字，后两步只从 json 读，正文里不手敲数字。

1. 物理量函数：单位在函数入口统一，`def B(x_m)` 只收米，调用处 `/100`。cm/m 混用会让理论曲线在原点直上直下。
2. 逐点表：正 / 反读数 → `(B正 + abs(B反)) / 2`，算相对误差；反向量必须 `abs`。
3. 汇总：均值、|最大|、rms。
4. 拟合：numpy 手写高斯-牛顿（`J.T@J` 求解），不装 scipy。
5. 不确定度：A 类 `s/√n`，B 类逐项 `a/√3`，合成后 k=1；**定位项要乘灵敏系数 `dB/dx`**，否则会漏掉最大的一项。
6. `json.dump(..., ensure_ascii=False)`。

自检判据：打印中心值实测 / 理论 / 相对误差、拟合残差 rms、合成不确定度；量与量之间能互相解释（例：拟合半径偏大 0.6% ↔ 中心场偏低 0.6%）。

## Step 2 出图（`figs.py`）

用 reportlab 矢量绘制 + fitz 转 PNG，复用 `scripts/chart.py`；matplotlib 报 `_ARRAY_API not found` 时不修依赖，直接用 reportlab。

- 每条曲线横坐标先转米再进公式。
- 误差棒用逐点 `u`（从 json 取）。
- PNG 里不带图号，图注在 docx 里写。
- `yr` 覆盖全部数据点：reportlab 没有裁剪区，超范围的点会画到坐标框外。
- 出完看图抽检：刻度可读、图例不压曲线、曲线不贴边、没有点落到框外。

## Step 3 填 docx（`build.py`）

**只用模板起草**（`memory.md` 补风格），不拿上一份成品当底稿。本课特有的五条：

1. 骨架复用：`Document(模板)` → 按段落文本定位（不写死段号）→ 删正文占位 → 按章重写 → 末尾「注意事项 / 落款」几段 `deepcopy` 回文末。
2. 搬预习稿的图：遍历 `a:blip` → `pre.part.related_parts[rid].blob` → `doc.part.get_or_add_image(BytesIO(blob))` 换新 rId；搬完确认没串图。
3. 封面字段全部重取：桌号看原始记录抬头、日期看课表、学号看 `config.yaml`；不沿用上一份。
4. 原始记录照片先转正：手机拍的草稿纸 EXIF 常无方向信息，同一批里就有横躺的；四个方向各存一张、看图认准表头朝向再用。图注写明「含姓名 学号 教师签字及日期」，夹在「二、实验操作与原始数据」标题下；该节标题下直接放照片，**不写过程说明段**——过程叙述归综述。
5. 思考题从手册【思考题】逐题照录，先抄题干再作答；节前写一段 ≤100 字小结。

公式一律 `$...$` 写 LaTeX，交给 `docx_fill.add_rich()` 转 Word 原生公式。

## Step 4 终检（四道，缺一不可）

前两道交给脚本，别手写：

```bash
python3 <技能目录>/scripts/proof.py "<根目录>/<N>" "*第<W>周.docx" --render <N>/_work/pages
```

它一次做完：页数与每页文字量（`<50` 字标空白可疑）、图片越版心、图注落单、
docx 段落在 PDF 里缺失、综述 / 重点 / 难点三处字数。退出码 1 = 有 WARN，逐条确认后再交付。

剩下两道只能看图：把 `pages/` 里的 PNG **逐页**看完——图有没有被分页从中间切断、
图注是否单独跑到次页页首、有没有整页空白、公式有没有变方框。

自己核字数时注意：`p.text` 不含 OMML 公式，含公式的段落会被数短；切段前先把
`w:t` 与 `m:t` 拼起来（`docx_fill.para_text` 的做法）再 `re.sub(r"\s+", "", ...)`。

字数以成品 docx 实测为准：限字段落按「综述段起点 → 下一节标题」整段求和；脚本计数器会漏小标题与图注。

完成判据：页数合理（双实验常为封面 + 4 页正文，单实验压缩后封面 + 2 页），逐页检查无溢出、无断图、无图注单独跑到次页页首、无整页空白。

## Step 5 交付（≤300 字）

四行，不铺陈：文件路径 + 页数 / 2–3 个带不确定度的核心结果 / 数据缺口（哪组没测，写「本次仅含 X 组」）/ 需要确认的事（签字、缺失数据）。
