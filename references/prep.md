# 分支 A：预习报告（`N-预/`）

用于课表下一周实验的预习稿。正式报告见 `references/report.md`。

## 0 输入

- `实验手册.pdf`、`ppt.pdf`（用户自己下好放进 `N-预/`）
- `课表.png` + `config.yaml` + `memory.md`
- 上一份预习稿（可选，**仅供文风参考，不作底稿**）

缺课件就先建目录让用户放，**不要编造课件内容**。

## 1 定字数上限

- 先数子实验 / 板块：只有一个 → 综述 ≤500 字（含小标题）；有两个 → 放宽到约 800 字。
- 上一份已交报告的字数只说明版式密度，**不是上限**；单实验按题面 500 压。
- 重点、难点各 ≤100 字。
- `memory.md` 里的字数约定优先于本节默认值。

## 2 取原理图

- 逐页摸底：`page.get_text()[:600]`、`len(page.get_image_info())`、`len(page.get_drawings())`，单实验取 2–3 张原理图（原理图 / 装置图）。
- 用 `scripts/pdf_extract_figs.py` 取原图；裁掉源图自带的「图N」、白底处理、逐张看图抽检。
- 落笔前给每张图定好配哪一段、编几号。

## 3 从模板起草

- **只用模板**：`open_base(模板/预习报告模板.docx, OUT)`。不复制上一份成品。
- 版式、字体、注意事项、落款全部继承模板；与上一份的差异靠 `memory.md` 补，不靠底稿。
- 先删正文占位段、只留封面与标题骨架。锚点按文本找：`（自述实验现象…）`、`2.实验重点`、`3.实验难点`、`注意事项：`。
- 新段插到锚点后：`p = doc.add_paragraph(); anchor._p.addnext(p._p)`，顺序插入即正序。

## 4 正文骨架

单实验也照此拆：

- `（1）<子实验名>`
- `现象：…` 先写看到什么，再写曲线 / 数值特征
- `原理与方法：…` 公式用 `$...$` 写 LaTeX，给关键常数、测量步骤
- `①… ②… ③…` 每项带参数、图号；选做单列 `④`
- 第二个子实验重复 `（2）…`

预习稿不放数据表格、误差计算、不确定度，那是正式报告的内容。

## 5 压缩与计数

- 压原理性套话 → 步骤并成短句，保留「现象 / 原理与方法」和 ①②③；公式、关键数值、图号不动。
- 字数以成品 docx 实测为准：取「综述」段到「实验重点」段之间的全部段落，`re.sub(r"\s+", "", t)` 后 `len`；脚本计数器会漏小标题和图注。
- 综述、重点、难点三个数分别报给用户。

完成判据：单实验综述 ≤500；重点 / 难点各 ≤100；超限项已压过或已说明。

## 6 导出、验版、交付

- 导出用 `scripts/export_pdf.py`；先复制到 `N-预/_work/preview.docx` 导出，再把 PDF 复制回 `N-预/` 的中文名。
- 单实验通常封面 + 2 页正文。
- **有视觉能力就逐页看**（见 `references/agents.md`）；没有就报页数与每页文字量，让用户过目。
- 用 `MEDIA:`（或宿主等价的附件方式）附 docx 与 PDF，正文报路径与三个字数。
